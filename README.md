# Simple Books API Automation Framework

This project is an API testing framework built with **C#** and **RestSharp**.

## 🛠️ Tools Used:
- **Language:** C#
- **IDE:** Visual Studio 2022
- **Testing Framework:** NUnit
- **API Library:** RestSharp
- **JSON Handler:** Newtonsoft.Json

## 🧪 Scenarios Automated:
1. API Status Check
2. User Registration (Token Generation)
3. Submitting a Book Order (Bearer Token Auth)

## 🚀 How to Run:
1. Clone the repository.
2. Open in Visual Studio 2022.
3. Build the solution to restore NuGet packages.
4. Open **Test Explorer** and click **Run All**.
